# Pokémon API Pokédex

Projeto desenvolvido com o objetivo de consumir uma API de Pokémon e apresentar suas informações em uma interface inspirada em uma Pokédex.

A aplicação utiliza **Vite** para o ambiente de desenvolvimento e a **PokéAPI** para obter dados dos Pokémon, trabalhando com requisições e manipulação de dados em JSON.

## Tecnologias utilizadas

- **Vite** — Ferramenta de build e ambiente de desenvolvimento.
- **JavaScript** — Lógica e funcionalidades da aplicação.
- **PokéAPI** — API utilizada para consultar informações dos Pokémon.
- **JSON** — Formato utilizado para receber e manipular os dados da API.
- **HTML e CSS** — Estruturação e estilização da interface.

## Funcionalidades

- Consumo de dados da PokéAPI.
- Consulta de informações dos Pokémon.
- Exibição de dados recebidos em formato JSON.
- Interface inspirada no universo Pokémon.

## Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/SEU-USUARIO/pokemon-api-pokedex.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd pokemon-api-pokedex
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Acesse o endereço disponibilizado pelo Vite no terminal.

## API utilizada

**PokéAPI:** https://pokeapi.co/

API pública que disponibiliza informações sobre Pokémon, incluindo nomes, imagens, tipos, habilidades e outras características.

## Objetivo do projeto

Praticar conceitos fundamentais de desenvolvimento web, especialmente o consumo de APIs externas, requisições HTTP, manipulação de dados JSON e construção de interfaces utilizando JavaScript e Vite.
